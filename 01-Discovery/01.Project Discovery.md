# Project

AMC/CAMC Service Management System

---

# Objective

Develop a lightweight centralized web application for managing:

- AMC contracts
- CAMC contracts
- Invoice tracking
- Financial tracking
- Billing schedules
- PM scheduling
- PM execution tracking
- Follow-up activities
- Engineer activities
- PM reports

Current process is maintained largely through Excel sheets and manual tracking.

Target outcome:

Single operational portal for Finance, Service and Management teams.

---

# Design Principles

The system shall intentionally remain simple.

Approved architecture principles:

✓ Single ASP.NET Core MVC project

✓ Avoid unnecessary abstractions

✓ No repository pattern

✓ No separate business layer project

✓ No generic repository

✓ No unit of work pattern

✓ EF Core directly through DbContext

✓ Lightweight service/helper classes only

Goal:

Fast implementation
Easy maintenance
Reduced complexity
